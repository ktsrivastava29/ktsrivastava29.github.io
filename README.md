# Developer website

Served by GitHub Pages from the public repo `ktsrivastava29.github.io`.

- `/` lists all apps. Use this URL as the **developer website** in Play Console.
- `/<app>/privacy-policy.html` is each app's privacy policy link for Play Console.
- `/app-ads.txt` (add after AdMob gives you the line) covers **every** app on the AdMob account.

New app: copy `kaagazlipi/` to a new folder, edit both pages, add an `<li>` in `index.html`.
